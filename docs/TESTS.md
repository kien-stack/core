# Tests

One section per feature, newest first.

## Upgrade test per chart (CI, 2026-11-26)

What: `hack/chart-upgrade-test.sh`, job `Upgrade` of `charts-test.yaml`.
For each changed `helm/platform/<chart>`, on a throwaway k3d cluster (k3s v1.33.13):
dependencies from main, the chart from main, then `helm upgrade` to the PR.

Pass: rollouts done, pods Ready, Jobs complete, Certificates / ExternalSecrets / CNPG Clusters Ready,
secrets generated by External Secrets unchanged (sha256).

Where: GitHub-hosted `ubuntu-latest`, one job per chart.
Run: https://github.com/kinopshq/core/actions/runs/45879907579 (PR #98, all 13 charts, 6 min 55 s wall time).

- infisical: 5 min 56 s (dependencies 3 min 14 s), 5 generated secrets unchanged
- monitoring: 4 min 55 s
- seaweedfs: 3 min 13 s
- cloudnative-pg: 2 min 15 s (test Postgres Cluster Ready before and after)
- external-secrets: 1 min 25 s (test ExternalSecret from the generator unchanged)
- argocd, cert-manager, traefik, metrics-server, reloader, openebs: 52 s to 1 min 22 s
- external-dns (not in the ApplicationSet), cilium (replaces the CNI): skipped

Found: cert-manager crashes without the Gateway API CRDs (`enableGatewayAPI: true`).
On a cluster, traefik (stage 1) installs them first. The test now applies them too.

Not tested:
- full release to release upgrade through ArgoCD (all components at once)
- cilium, external-dns
- data kept in databases and S3 across an upgrade (only generated secrets are compared)
- this PR changes no chart: every upgrade above is main -> same chart (no-op), it proves the harness, not a bump
